# slack-bot

| Commands                         | Returns                  |
| -------------------------------- | ------------------------ |
| /bing-bong-bot-here-ping         | returns ping time        |
| /bing-bong-bot-here-world        | Returns hello world!     |
| /bing-bong-bot-here-im-a-bot-too | returns secret message :0|

A simple Slack bot that posts (hopefully) funny messages when asked, using javascript and the Slack API. Made for Stardance 2026
